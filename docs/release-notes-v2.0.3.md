# 小橙看班联动 v2.0.3 —— 调课联动加固

> 配合「QQ 调课同步 v1.4.1」的稳定性加固，统一日志与桥接契约。

## 🆕 变更

- **统一日志前缀 `[调课中枢]`**：转发日志、联动连接日志都带同一标签，
  在 ClassIsland 日志里能和 QQ 来源的调课日志一起筛出来。
- **桥接契约版本检查**：连接「QQ 调课同步」时读取其 `ContractVersion`
  （当前为 `2`，表示支持批量/互换），并打印版本号；对方未声明版本时只警告、仍尝试转发，
  保证两个插件可以各自独立升级。

## ✅ 验证

- 与 `qq.classsync 1.4.1.0` 同时加载：`xiaocheng.link 2.0.3.0` 正常启动
- 日志示例：`[调课中枢] 调课联动已连接「QQ 调课同步」插件（契约版本 2）。`
- 原有窗口提醒 / 考试提醒 / 语音对讲功能不受影响

## 🚀 升级

1. 下载 `XiaoChengLink.cipx` 覆盖安装
2. 与 QQ 调课同步一起升级时只需重启一次 ClassIsland

## ⚠️ 说明

- 兜底轮询 `tiaokeLinkPollSeconds` 默认 30 秒，课堂机觉得开销大可调大或设 0
